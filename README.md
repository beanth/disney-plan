# disney-plan

A self-contained trip guide for Disneyland, 18–22 August 2026 — party of four.

`index.html` carries all content, core styles and scripts; `festive.css` is the
seasonal decoration layer and the page works identically without it. There is no
build step and no dependencies. Open it from disk, or let GitHub Pages serve it
from `main`.

The page is `noindex` and the link is meant to be passed around directly, not
found. It names exact travel dates, so treat the URL as semi-private.

After the trip this is a keepsake, not a live document — the prices and times go
stale the moment it's over. Archive it rather than updating it.
